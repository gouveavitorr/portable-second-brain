# 🎯 Objetivos de Longo Prazo

Estes **não** são tarefas e nunca aparecem na tela "Agora" — não existe botão *feito*
pra eles. Ficam aqui pra dar direção: quando você não souber qual projeto ou tarefa
merece atenção, pergunte qual deles cada coisa empurra.

O app lê os títulos daqui e cruza com as tarefas que têm `objetivo:<slug-do-título>`,
pra mostrar o que está empurrando cada objetivo.

> Exemplos. **Troque pelos seus.**

## Aprender uma habilidade nova

Direção, não tarefa. Escolha uma (um instrumento, um idioma, cozinhar melhor) e, quando
quiser puxar pra frente, vira uma tarefa concreta no [[inbox]] — o primeiro passo aparece
na triagem.

## Ter uma reserva de emergência

O que empurra isso é a caixinha da reserva no [[financeiro]] (a meta é o custo fixo × 7).
Cada depósito na tela Agora faz o Pokémon da reserva crescer.

## Nota

Se um objetivo ficar meses sem nada empurrando ele, isso é informação — ou o objetivo
não é real, ou está na hora de criar tarefas pra ele. Nenhuma das duas conclusões é
motivo pra culpa.
